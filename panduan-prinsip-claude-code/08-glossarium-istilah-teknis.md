# 📖 Glossarium Istilah Teknis

> Daftar istilah teknis Inggris-Indonesia yang sering muncul di panduan ini
> Khusus untuk pemula yang baru belajar tentang AI Agent dan Claude Code

---

## 🅰️ Istilah Utama

| Istilah Inggris | Istilah Indonesia | Penjelasan |
|----------------|-------------------|------------|
| **Agent** | **Agen** | Program AI yang bisa bertindak secara mandiri untuk mencapai tujuan tertentu |
| **AI (Artificial Intelligence)** | **Kecerdasan Buatan** | Teknologi yang membuat komputer bisa berpikir dan belajar seperti manusia |
| **API (Application Programming Interface)** | **Antarmuka Pemrograman Aplikasi** | Jembatan yang memungkinkan dua program berbeda untuk berkomunikasi |
| **Autonomous** | **Otonom** | Bekerja sendiri tanpa perlu campur tangan manusia |

## 🅱️ Istilah Penting

| Istilah Inggris | Istilah Indonesia | Penjelasan |
|----------------|-------------------|------------|
| **CLI (Command Line Interface)** | **Antarmuka Baris Perintah** | Cara berinteraksi dengan komputer melalui teks/ketik, bukan grafis |
| **Composable** | **Dapat Dirangkai** | Skill yang bisa digabungkan dengan skill lain untuk membentuk workflow |
| **Context Window** | **Jendela Konteks** | Memori sementara AI — seberapa banyak informasi yang bisa diingat AI dalam satu sesi |
| **Deterministic** | **Deterministik** | Selalu menghasilkan output yang sama untuk input yang sama |
| **Discovery Prompt** | **Prompt Penemuan** | Pertanyaan khusus yang dirancang untuk menemukan informasi atau pola tertentu |

## 🅲 Istilah Teknis

| Istilah Inggris | Istilah Indonesia | Penjelasan |
|----------------|-------------------|------------|
| **Edge Case** | **Kasus Pinggiran** | Situasi langka atau tidak biasa yang bisa menyebabkan error |
| **Flag** | **Bendera/Tanda** | Pengaturan khusus di file konfigurasi untuk mengaktifkan/menonaktifkan fitur |
| **Frontmatter** | **Metadata Awal** | Informasi pengaturan di bagian paling atas file (diapit `---`) |
| **Global Skills** | **Skill Global** | Skills yang tersedia di semua proyek, di mana pun kamu bekerja |
| **Helper Skill** | **Skill Pembantu** | Skill yang hanya digunakan oleh skill lain, tidak dipanggil langsung oleh pengguna |
| **Iteration** | **Iterasi** | Proses mengulang dengan perbaikan bertahap |
| **Leverage** | **Daya Ungkit** | Kemampuan untuk mendapatkan hasil maksimal dengan usaha minimal |

## 🅳 Istilah Kunci Claude Code

| Istilah Inggris | Istilah Indonesia | Penjelasan |
|----------------|-------------------|------------|
| **Model** | **Model** | AI itu sendiri (Claude Sonnet, Claude Opus, dll.) |
| **MCP (Model Context Protocol)** | **Protokol Konteks Model** | Standar untuk menghubungkan Claude dengan tools eksternal (browser, database, dll.) |
| **Non-Deterministic** | **Non-Deterministik** | Output bisa berbeda meskipun inputnya sama (berlawanan dengan deterministik) |
| **One-Shot** | **Sekali Pakai** | Tugas yang hanya dilakukan satu kali, tidak perlu dibuatkan skill khusus |
| **Pipeline** | **Jalur Proses** | Rangkaian langkah berurutan yang harus dilalui untuk menyelesaikan pekerjaan |
| **Progressive Disclosure** | **Pengungkapan Bertahap** | Informasi dimuat sedikit demi sedikit, bukan semuanya sekaligus |
| **Project Skills** | **Skill Proyek** | Skills yang hanya tersedia di proyek tertentu |
| **Prompt** | **Perintah/Instruksi** | Teks yang kamu kirim ke AI untuk memintanya melakukan sesuatu |

## 🅴 Istilah Lainnya

| Istilah Inggris | Istilah Indonesia | Penjelasan |
|----------------|-------------------|------------|
| **Reuse** | **Pakai Ulang** | Menggunakan sesuatu yang sudah ada untuk keperluan lain |
| **Runtime** | **Waktu Jalan** | Saat program sedang berjalan/beroperasi |
| **Session** | **Sesi** | Satu rangkaian percakapan dengan Claude Code |
| **Skill** | **Keahlian/Kemampuan** | Folder berisi instruksi untuk Claude — **istilah inti panduan ini** |
| **Slash Command** | **Perintah Garis Miring** | Cara memanggil skill dengan `/nama-skill` |
| **Terminal / Command Prompt** | **Baris Perintah** | Antarmuka teks untuk berinteraksi dengan komputer |
| **Throwaway** | **Sekali Pakai** | Dibuat untuk satu tugas, lalu dibuang setelah selesai |
| **Token** | **Token** | Unit biaya komputasi AI — setiap kata/karakter yang diproses menghabiskan token |
| **Tool** | **Alat** | Script atau program yang membantu Claude melakukan tugas spesifik |
| **Workflow** | **Alur Kerja** | Rangkaian langkah untuk menyelesaikan suatu tugas |
| **YAML** | **YAML** | Format file konfigurasi yang mudah dibaca manusia |

## 🎯 Istilah yang PALING Penting untuk Diingat

| Istilah | Kenapa Penting |
|---------|----------------|
| **Skill** | Ini adalah KONSEP INTI dari semua 5 prinsip. Skill = folder + instruksi |
| **Tool** | Ini adalah LEVERAGE terbesar. Investasi di tools, bukan di prompt indah |
| **Token** | Ini adalah MATA UANG. Setiap prompt menghabiskan token. Gunakan dengan bijak |
| **Composable** | Ini adalah STRATEGI. Skill kecil yang bisa dirangkai > satu skill raksasa |
| **Prompt** | Ini adalah C ARA BERKOMUNIKASI dengan AI. Format output adalah bagian dari prompt |
