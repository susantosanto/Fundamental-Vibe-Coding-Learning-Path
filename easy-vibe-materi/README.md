## 🎓 JALUR BELAJAR YANG DISARANKAN

### Untuk Pemula (Belum pernah coding)
```
1. BAB 1: Pengenalan Vibe Coding
   → Pahami konsep dasar dan mengapa ini mungkin
   
2. BAB 2: Alat AI IDE  
   → Install Cursor dan coba
   
3. BAB 4: Membangun Prototype
   → Ikuti tutorial Todo List
   
4. BAB 3: Mencari Ide Produk
   → Temukan ide untuk project sendiri
   
5. BAB 5: Integrasi AI
   → Tambahkan fitur AI ke project Anda
   
6. BAB 6: Praktik Proyek Lengkap
   → Bangun project yang lebih kompleks
```

### Untuk Menengah (Sudah pernah coding)
```
1. BAB 2: Alat AI IDE
   → Pelajari fitur advanced
   
2. BAB 5: Integrasi AI
   → Pahami cara integrasi API
   
3. BAB 6: Praktik Proyek Lengkap
   → Ikuti project TaskFlow
   
4. BAB 7: Lampiran Bisnis
   → Pahami cara membuat produk yang laku
   
5. BAB 9: Lampiran Teknis
   → Pelajari troubleshooting dan tools

6. BAB 10-13: Framework Validasi
   → Pelajari sumber ide, Double Diamond, JTBD, The Mom Test
   
7. BAB 14-15: 100+ Ide Produk
   → Dapatkan inspirasi dari skenario B2B & B2C
   
8. BAB 16: Tutorial Praktis
   → Praktik langsung membuat game & website dengan AI
```

### Untuk Yang Ingin Eksplorasi Ide
```
1. BAB 14: Skenario B2B
   → Cari ide di sektor yang Anda kenal
   
2. BAB 15: Skenario B2C
   → Cari ide berdasarkan minat pribadi
   
3. BAB 10-13: Framework Validasi
   → Validasi ide sebelum mulai coding
   
4. BAB 16: Tutorial Praktis
   → Praktikkan dengan tutorial yang ada
```

### 🔑 Konsep Kunci yang Harus Dipahami

1. **Vibe Coding**: Pemrograman dengan berbicara ke AI
2. **AI IDE**: Alat pemrograman dengan AI terintegrasi

4. **MVP**: Versi sederhana produk yang masih berguna
5. **Prototype**: Versi awal untuk testing
6. **Integrasi API**: Menyambungkan dengan layanan AI
