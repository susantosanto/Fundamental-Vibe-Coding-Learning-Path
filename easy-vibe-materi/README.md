## 🎓 JALUR BELAJAR YANG DISARANKAN

### Untuk Pemula (Belum pernah coding)
```
1. BAB 1: Pengenalan Vibe Coding
   → Pahami konsep dasar dan mengapa ini mungkin
   
2. BAB 2: Alat AI IDE  
   → Install Cursor dan coba
   
3. BAB 4: Membangun Prototype
   → Ikuti tutorial Todo List
   
4. BAB 3: Mencari Ide Produk
   → Temukan ide untuk project sendiri
   
5. BAB 5: Integrasi AI
   → Tambahkan fitur AI ke project Anda
   
6. BAB 6: Praktik Proyek Lengkap
   → Bangun project yang lebih kompleks
```

### Untuk Menengah (Sudah pernah coding)
```
1. BAB 2: Alat AI IDE
   → Pelajari fitur advanced
   
2. BAB 5: Integrasi AI
   → Pahami cara integrasi API
   
3. BAB 6: Praktik Proyek Lengkap
   → Ikuti project TaskFlow
   
4. BAB 7: Lampiran Bisnis
   → Pahami cara membuat produk yang laku
   
5. BAB 9: Lampiran Teknis
   → Pelajari troubleshooting dan tools
```
