# fundamental-vibe-coding

AI Engineering Learning Path - 6 Fase dari fundamental hingga advanced AI orchestration.

## Fase Pembelajaran

1. **fase-1-arsitektur-dasar** — Fundamental arsitektur AI dan prompt engineering
2. **fase-2-ai-tools-dasar** — Pengenalan tools AI (Claude Code, Gemini CLI, dll)
3. **fase-3-advanced-workflows** — Workflow lanjutan dengan AI agents
4. **fase-4-deep-system-design** — System design untuk AI-powered applications
5. **fase-5-scenario-praktis** — Skenario praktis implementasi AI
6. **fase-6-advanced-opencode** — Advanced OpenCode dan agent orchestration

## Core Principles

- **Learn by doing** — Praktik langsung, bukan teori saja
- **Progressive complexity** — Dari fundamental ke advanced
- **Agent-first** — Memanfaatkan AI agents untuk optimalisasi workflow

## Guidelines

1. Gunakan Bahasa Indonesia untuk penjelasan konsep
2. Prioritaskan praktik langsung dibanding teori
3. Hubungkan setiap konsep dengan use case dunia nyata (terutama administrasi sekolah)
4. Berikan coding contoh yang konkret dan bisa langsung dijalankan
