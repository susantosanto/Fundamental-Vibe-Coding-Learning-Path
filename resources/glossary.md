# 📚 Glosarium — Kamus Istilah Teknis

## A

| Istilah | Arti |
|---|---|
| **ACID** | Atomicity, Consistency, Isolation, Durability — properti transaksi database |
| **API** | Application Programming Interface — antarmuka komunikasi antar software |
| **API Gateway** | Single entry point untuk semua client ke microservices |
| **Asynchronism** | Pola eksekusi di mana tugas dijalankan di background |
| **Availability** | Kemampuan sistem untuk tetap merespons meskipun ada gangguan |
| **Autonomous Agent** | AI yang bekerja mandiri tanpa intervensi manusia |

## B

| Istilah | Arti |
|---|---|
| **Back Pressure** | Mekanisme untuk mengatur kecepatan producer agar tidak overload consumer |
| **Bloom Filter** | Struktur data untuk cek keanggotaan dengan cepat dan hemat memory |

## C

| Istilah | Arti |
|---|---|
| **Cache** | Penyimpanan data sementara berkecepatan tinggi |
| **CAP Theorem** | Consistency, Availability, Partition Tolerance — hanya bisa pilih 2 dari 3 |
| **CDN** | Content Delivery Network — server global untuk konten statis |
| **Circuit Breaker** | Pola untuk fail fast saat service downstream gagal |
| **CLAUDE.md** | File konteks proyek untuk Claude Code |
| **Consistency** | Data yang sama di semua node |
| **CQRS** | Command Query Responsibility Segregation — pisahkan read dan write |

## D

| Istilah | Arti |
|---|---|
| **DNS** | Domain Name System — menerjemahkan domain ke IP |
| **Denormalization** | Duplikasi data untuk menghindari JOIN yang mahal |

## E / F / G / H

| Istilah | Arti |
|---|---|
| **Event Sourcing** | Menyimpan semua perubahan (events), bukan state saat ini |
| **Fail-over** | Mekanisme otomatis beralih ke server cadangan |
| **gRPC** | RPC modern dari Google, menggunakan Protocol Buffers |
| **Horizontal Scaling** | Menambah jumlah server untuk meningkatkan kapasitas |
| **Hooks** | Shell commands yang dijalankan otomatis saat event tertentu |

## L / M / N

| Istilah | Arti |
|---|---|
| **Latency** | Waktu untuk menyelesaikan 1 operasi |
| **Load Balancer** | Mendistribusikan traffic ke banyak server |
| **Message Queue** | Antrian untuk komunikasi antar service |
| **Microservices** | Arsitektur dengan service-service kecil dan independen |
| **NoSQL** | Database non-relasional (MongoDB, Redis, Cassandra) |
| **Monolith** | Arsitektur dengan satu aplikasi besar untuk semua fitur |

## R / S

| Istilah | Arti |
|---|---|
| **RDBMS** | Relational Database Management System (MySQL, PostgreSQL) |
| **REST** | Representational State Transfer — arsitektur API populer |
| **Reverse Proxy** | Server di depan backend untuk caching, SSL, security |
| **RPC** | Remote Procedure Call — panggil function di server lain |
| **Sharding** | Memecah database besar ke banyak server berdasarkan key |
| **Skills** | Kemampuan reusable untuk Claude Code |
| **Sub-agents** | AI specialist untuk domain tertentu |

## T / U / V/W

| Istilah | Arti |
|---|---|
| **Throughput** | Jumlah operasi per satuan waktu |
| **TTL** | Time To Live — berapa lama data di-cache |
| **TCP** | Transmission Control Protocol — reliable, connection-oriented |
| **UDP** | User Datagram Protocol — cepat, connectionless |
| **Vertical Scaling** | Meningkatkan kapasitas server yang ada (RAM, CPU) |
| **Vibe Coding** | Mindset AI-assisted development yang iteratif |
| **WebSocket** | Protokol komunikasi dua arah real-time |
