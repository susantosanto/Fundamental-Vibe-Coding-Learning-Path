# Fase 5: Scenario Praktis

> **Tujuan**: Gunakan OpenCode untuk selesaikan tugas nyata. Fokus ke 2 jalur: Programming dan Office Data.

## 🎯 Pilih Jalur Belajar

### 💻 Jalur B: Programmer (7 modul)
Untuk developer: coding, debugging, refactoring, testing, CI/CD, custom agents.

| Modul | Topik | Estimasi |
|-------|-------|----------|
| B1 | Development Daily | 25 menit |
| B2 | Refactoring & Testing | 25 menit |
| B3 | Dokumentasi & Git | 20 menit |
| B4 | CI/CD Integration | 25 menit |
| B5 | Custom Dev Agents | 30 menit |

### 📊 Jalur C: Office & Data (3 modul)
Untuk administrasi: file management, data processing, automation.

| Modul | Topik | Estimasi |
|-------|-------|----------|
| C1 | File Management | 20 menit |
| C2 | Pengolahan Data (CSV/JSON) | 25 menit |
| C4 | Otomatisasi Script | 25 menit |

## 📋 Prerequisites
- Selesai Fase 2 (AI Tools Dasar)
- Selesai Fase 3 (Advanced Workflows)
- OpenCode terinstall dan terhubung ke model

## 🚀 Cara Mulai
1. Pilih jalur yang sesuai kebutuhan
2. Mulai dari modul pertama di jalur tersebut
3. Praktikkan langsung di OpenCode
4. Lanjut ke modul berikutnya

## 💡 Tips
- Tidak perlu semua jalur. Pilih satu, kuasai, baru eksplor lainnya.
- Setiap modul bisa langsung loncat ke yang dibutuhkan.
- Gunakan Plan mode untuk planning, Build mode untuk eksekusi.
- Semua modul pakai Bahasa Indonesia yang mudah dipahami.
