> **Untuk Pemula Absolute — Tidak Perlu Pengalaman Coding Sebelumnya**
>
> *"Kamu tidak perlu jadi programmer dulu untuk bisa membuat aplikasi dengan AI. Tapi kamu perlu paham cara bicara dengan AI."*

## 🗺️ LEARNING PATH (6 Fase)

```
FASE 1 ──→ FASE 2 ──→ FASE 3 ──→ FASE 4 ──→ FASE 5 ──→ FASE 6
  │           │           │           │           │           │
  ▼           ▼           ▼           ▼           ▼           ▼
Prompt     Teknik     Prompt→     Logika &    Bangun      Aplikasi
Dasar      Prompting   Kode       Arsitektur  Aplikasi    Semi-Kompleks
```

### ✨ FASE 1: Prompting Dasar (Hari 1-2)
**Dari "halo" sampai bisa bikin prompt yang benar**

- Apa itu prompt? Kenapa AI kadang ngaco?
- 3 komponen prompt: **Konteks → Tugas → Format**
- Latihan: bikin prompt untuk hal sehari-hari
- **Output:** Kamu bisa menulis prompt yang jelas dan terstruktur

### ✨ FASE 2: Teknik Prompting (Hari 3-5)
**Pattern yang bikin AI selalu ngasih hasil berkualitas**

- Persona pattern: "Kamu adalah tutor JavaScript..."
- Chain-of-Thought: Minta AI mikir step-by-step
- Few-Shot: Kasih contoh biar AI paham
- Iterative Refinement: Perbaiki hasil secara bertahap
- **Output:** Kamu bisa dapat kode yang tepat dari AI

### ✨ FASE 3: Dari Prompt ke Kode (Hari 6-8)
**Belajar baca kode yang dihasilkan AI — tanpa takut**

- Struktur dasar JavaScript: variable, function, kondisi
- Cara AI menerjemahkan prompt ke kode
- Debugging sederhana: baca error, cari masalah
- **Output:** Kamu paham kode dasar yang dihasilkan AI

### ✨ FASE 4: Logika & Arsitektur Sederhana (Hari 9-11)
**Mulai berpikir seperti arsitek aplikasi**

- Apa itu arsitektur? Analogi bangun rumah
- Pemisahan: HTML (struktur) + CSS (tampilan) + JS (logika)
- Flow aplikasi: Input → Proses → Output
- Pola sederhana: Function = Unit kerja kecil
- **Output:** Kamu paham struktur dasar sebuah aplikasi web

### ✨ FASE 5: Bangun Aplikasi (Hari 12-16)
**Bikin aplikasi nyata step-by-step**

- Project 1: Kalkulator Sederhana (10 baris JS)
- Project 2: Catatan App (30 baris JS)  
- Project 3: Pengelola Tugas (50 baris JS)
- Setiap project: Prompt → Desain → Kode → Review
- **Output:** 3 aplikasi HTML/CSS/JS yang berfungsi

### ✨ FASE 6: Aplikasi Semi-Kompleks (Hari 17-21)
**Gabungin semua: arsitektur rapi + fitur lengkap**

- Dashboard Keuangan Pribadi
- Struktur folder yang rapi
- Komponen yang bisa dipisah
- State management sederhana
- **Output:** 1 aplikasi lengkap dengan arsitektur bersih

## 🎯 CARA PAKAI MODUL INI

### Setiap Fase:
```
1. BACA panduan (10-15 menit)
2. PRAKTEK langsung (15-20 menit)  
3. KERJAKAN latihan (10-15 menit)
4. REVIEW & catat insight (5 menit)
─────────────────────────────────
TOTAL: 40-55 menit per fase
```

### Tips Penting:
```javascript
// ❌ JANGAN lakukan ini:

- 1 fase per hari, konsisten

```
