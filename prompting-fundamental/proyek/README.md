# 📂 Proyek Latihan

> Folder ini berisi contoh aplikasi yang bisa kamu buat setelah belajar prompt engineering.

---

## 📋 Daftar Project

| Project | Level | Baris JS | Konsep yang Dipelajari |
|---------|-------|----------|------------------------|
| **01-kalkulator** | 🟢 Mudah | ~30 baris | Input → Proses → Output, Event handling |
| **02-catatan** | 🟡 Sedang | ~100 baris | CRUD, localStorage, Filter |
| **03-dashboard-keuangan** | 🔴 Semi-Kompleks | ~200+ baris | Arsitektur multi-file, State management, Grafik |

---

## 🎯 Cara Pakai

### 1. Buka Langsung
Double click file `index.html` di folder project → otomatis terbuka di browser.

### 2. Pelajari Kodenya
Buka file HTML di editor, baca kode dan komentarnya.

### 3. Modifikasi
Ubah sesuai keinginanmu. Coba tambah fitur baru!

### 4. Buat dari Awal
Gunakan prompt di Fase 5 untuk membuat project serupa dari AI.

---

## 📖 Untuk Pemula

**Urutan belajar yang disarankan:**

1. **Buka `01-kalkulator/index.html`** → Pahami struktur HTML, CSS, JS
2. **Coba modifikasi** → Ubah warna, tambah tombol
3. **Lanjut ke `02-catatan/index.html`** → Pelajari CRUD & localStorage
4. **Buat sendiri** → Ikuti panduan di Fase 5 untuk bikin dari awal

---

## 🚀 Mau Buat Project Sendiri?

Gunakan template prompt ini:

```text
Buatkan aplikasi [nama] dengan:
- HTML: struktur halaman
- CSS: styling modern, warna [pilihan warna]
- JS: function terpisah untuk setiap fitur
- localStorage untuk menyimpan data

Fitur:
1. [fitur 1]
2. [fitur 2]
3. [fitur 3]
```
